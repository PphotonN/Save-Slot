# Save Slot

**Save Slot** — кросплатформний онлайн-пошуковик відеоігор і локальний менеджер власних списків. Сторінка працює на GitHub Pages без облікового запису та без API-ключа.

## Принцип роботи

- каталог не зашитий у сайт і завантажується онлайн;
- Wikidata використовується для пошуку, платформ, жанрів, років, описів та ідентифікаторів;
- Wikipedia та Wikimedia Commons використовуються як основні й резервні джерела зображень;
- доступні оцінки гравців догружаються окремо й не обмежують кросплатформний каталог;
- локально зберігаються лише списки, статуси, нотатки, пріоритети й особисті оцінки.

## Можливості v0.4

- автоматичний стартовий список одразу після відкриття сторінки;
- пошук ігор для ПК, PlayStation, Xbox, Nintendo, Sega, портативних і ретро-систем;
- реактивні фільтри за платформою, жанром, роком та доступними оцінками гравців;
- кілька резервних обкладинок із автоматичним перемиканням при помилці;
- «Випадкова п’ятірка» — п’ять різних ігор однієї платформи;
- алгоритм добірки враховує популярність, різноманітність жанрів, різні роки, схожість назв і попередні рекомендації;
- кілька локальних списків, статуси проходження, пріоритети, нотатки й особисті оцінки;
- імпорт та експорт JSON;
- PWA-кеш інтерфейсу з актуалізацією через мережу.

