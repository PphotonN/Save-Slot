# Save Slot

Мінімалістичний локальний інструмент для пошуку ігор і створення власних списків.

## Поточна версія

- темний мінімалістичний піксельний інтерфейс;
- картки ігор у формі стилізованих картриджів;
- інтерактивний 3D-нахил карток під курсором;
- пошук за назвою, жанром і платформою;
- фільтри за платформою, жанром, рейтингом і тривалістю;
- окремий режим прихованих перлин;
- сортування за рейтингом, тривалістю, роком і назвою;
- локальне автозбереження списку через `localStorage`;
- імпорт та експорт списку у форматі JSON;
- адаптивний інтерфейс для ПК і мобільних пристроїв;
- статична архітектура без сервера та збірки.

## Локальний запуск

Найпростіше відкрити `index.html` у браузері. Для коректнішої роботи браузерного сховища та зовнішніх зображень бажано запустити локальний HTTP-сервер:

```bash
python -m http.server 8080
```

Після цього відкрити:

```text
http://localhost:8080
```

## Збереження списків

Активний список автоматично зберігається у браузері. Кнопка **Експорт** створює JSON-файл, який можна імпортувати на іншому пристрої або відкрити пізніше для подальшого редагування.

Поточний формат:

```json
{
  "format": "save-slot-list",
  "version": 1,
  "name": "Мій список ігор",
  "exportedAt": "2026-07-27T00:00:00.000Z",
  "games": []
}
```

## Дані ігор

Поточна версія використовує невеликий демонстраційний каталог у `app.js`. Наступний етап — підключення реального каталогу та користувацьких рейтингів із доступних API, а також тривалості проходження.

Запланована структура джерел:

- IGDB або RAWG — каталог, платформи, жанри та обкладинки;
- користувацькі рейтинги без рейтингу критиків;
- HowLongToBeat — основний сюжет, додаткове проходження та 100%;
- локальний кеш для зменшення кількості запитів.
