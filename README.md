# Save Slot

Save Slot — онлайн-пошуковий менеджер відеоігор. Каталог не вбудований у сайт: пошук і метадані надходять із Wikidata, а рейтинг гравців — зі Steam, коли у Wikidata вказано Steam Application ID.

## Основна логіка

- онлайн-пошук без API-ключів;
- Wikidata: назви, описи, платформи, жанри, дати, розробники, видавці та зовнішні ідентифікатори;
- Steam: частка позитивних відгуків та загальна кількість відгуків;
- надійне сортування рейтингу за нижньою межею Вілсона, яке враховує обсяг вибірки;
- точні вертикальні Steam Library-обкладинки, коли доступний Steam ID;
- Wikimedia Commons як запасне джерело зображення;
- локально зберігаються лише особисті списки, статуси, пріоритети, оцінки та нотатки;
- імпорт та експорт JSON;
- PWA-кешує лише оболонку застосунку, а не каталог ігор.

## Запуск

```bash
python -m http.server 8080
```

Відкрити `http://localhost:8080`.

## Джерела

- Wikidata Action API (`wbsearchentities`, `wbgetentities`);
- Steam User Reviews endpoint;
- Wikimedia Commons та Steam CDN для зображень.

Steam не дозволяє стабільно читати свої JSON-відповіді напряму з усіх браузерів через CORS. Save Slot спершу виконує прямий read-only запит, а потім використовує публічні CORS-проксі як резервний шлях. Жодні ключі або облікові дані не передаються.
