# Save Slot for Android

Повністю новий нативний клієнт Save Slot, створений на Kotlin і Jetpack Compose. Він не використовує WebView та не залежить від GitHub Pages.

## Реалізовано

- онлайн-пошук через Wikidata без API-ключа;
- додаткове джерело RAWG з ключем користувача;
- Steam-рейтинг для записів зі Steam App ID;
- стабільне об’єднання джерел без підміни вже обраної гри;
- фільтри за платформою, жанром і роками, окреме сортування;
- випадкова гра та випадкова п’ятірка без повторів;
- псевдо-3D слот і анімація польоту картриджа;
- локальна бібліотека зі статусом, списком, пріоритетом, оцінкою та нотатками;
- імпорт і експорт JSON;
- дисковий кеш на 12 годин та ручне очищення;
- український інтерфейс без CRT/scanline-фільтрів і декоративного нахилу тексту.

## Запуск

Відкрити каталог `android` в Android Studio або виконати:

```bash
gradle :app:assembleDebug
```

APK буде створено в `app/build/outputs/apk/debug/app-debug.apk`.

## Джерела

Wikidata увімкнена за замовчуванням. RAWG вмикається автоматично після введення API-ключа у параметрах. Ключ зберігається лише у локальних налаштуваннях Android.
